# AI Use Statement

AI-assisted coding and writing tools were used during project finalization. Their use included:

- auditing repository structure and notebook execution state;
- identifying reproducibility, stale-output and leakage-documentation gaps;
- drafting/refactoring notebook code for path safety, generated evidence, feature-set comparison and reproducible hyperparameter tuning;
- drafting project documentation from generated tables and notebook logic;
- implementing and validating the browser-only K-Means deployment; and
- checking consistency between Python artifacts and JavaScript inference.

Controls applied:

- Model outputs and metrics were generated by executed code, not supplied as unverifiable AI claims.
- The saved models were not retrained merely to improve scores.
- The chronological validation/test protocol was enforced in code.
- Dataset definitions were derived from the actual source schema and feature-engineering notebooks.
- AI suggestions were checked through notebook execution, assertions, artifact comparisons, static syntax checks, and repository audits.
- No credentials, private APIs or uploaded user CSV data were introduced into the deployment.

The group remains responsible for reviewing the repository, confirming that this disclosure meets university policy, and describing individual learning and contribution accurately. This statement does not replace member-specific declarations required by the institution.
