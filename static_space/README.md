# Football Team Performance Profiler

A browser-only football team profiling application. The saved StandardScaler
parameters and K-Means centroids are evaluated locally in JavaScript; uploaded
CSV data never leaves the user's browser.

This application assigns historical profiles. It does not predict future match
results or guarantee performance.
